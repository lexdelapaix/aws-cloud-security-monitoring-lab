# Investigations

This directory contains documented security investigations performed against telemetry generated by the AWS Cloud Security Monitoring Lab.

Each investigation will document the analyst workflow from initial detection through classification and recommended response.

Investigation documentation will include:

1. Summary
2. Detection source
3. Initial evidence
4. Investigation steps
5. Event correlation
6. Classification
7. Potential impact
8. Recommended response
9. Lessons learned

All investigations will use controlled lab activity and sanitized information.
