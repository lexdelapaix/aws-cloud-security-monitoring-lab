# Detection Engineering

This directory contains security detections developed for the AWS Cloud Security Monitoring Lab.

Detections will focus on identifying suspicious or potentially unauthorized activity within the environment.

Planned detection categories include:

* Suspicious authentication activity
* IAM changes
* Privilege escalation
* Unusual API activity
* Security group modifications
* Resource changes
* Abnormal administrative behavior

Each detection will document:

* Detection objective
* Data source
* Detection logic
* Relevant fields
* Expected behavior
* Suspicious behavior
* Investigation considerations
